# 版本規劃文件

> 規劃聲明：本目錄內容是可調整的規劃草案，不構成功能、日期或上游 OpenAI 規則的承諾；實際發布範圍以對應 Release Milestone 與已完成的驗收紀錄為準。

本目錄只提供版本文件導覽。每個版本的範圍、工作項目、驗收案例與發布門檻，都只記錄在該版本自己的文件中，避免不同版本互相混用。

## 使用規則

- 所有命令預設從 repository 根目錄執行。
- 任務只有在程式碼、測試或操作證據完成後才能勾選。
- 驗收結果必須填入版本文件末尾的「驗收紀錄」。
- 任何真實 Admin API Key、Organization ID、Project ID 或未匿名化 API 回應都不得提交至 Git。
- 未通過所有 `P0` 驗收案例，不得建立正式版本 tag。
- 版本範圍若有調整，必須先更新對應版本文件的「範圍內／範圍外」。

## 狀態定義

本輪採用[整合交付決策](consolidated-delivery.md)：未發布的 v0.2–v0.5 工作合併進 v1 release-candidate，不建立內容與版本語意不符的中間 tag。

- `未開始`：尚未進入實作。
- `進行中`：已有負責人並正在執行。
- `待驗收`：功能完成，等待執行本文件的驗收案例。
- `已完成`：所有發布門檻通過並已發布對應 tag。
- `阻擋`：存在無法由版本內工作排除的外部依賴。
