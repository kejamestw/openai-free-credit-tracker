# v0.1.0 執行與驗收計畫

> 規劃聲明：本文件是可調整的規劃草案，不構成功能、日期或上游 OpenAI 規則的承諾；實際發布範圍以對應 Release Milestone 與已完成的驗收紀錄為準。

## 版本資料

- 狀態：未開始
- 版本主題：Windows 核心正式版
- 前置版本：`v0.1.0-alpha.1`
- 建議工期：單人 4–7 個工作天
- 發布產物：Windows portable EXE、`SHA256SUMS.txt`、Changelog

## 版本目標

把目前的 alpha 原型整理成第一個可交付的 Windows 正式版。使用者應能在乾淨的 Windows 環境下載 EXE、開啟本機 Web UI、輸入 Admin API Key，並正確查看兩個免費群組、incentivized tier 用量與模型費用 Tooltip。

## 成功結果

一位沒有安裝 Python、沒有 clone repository 的 Windows 使用者，可以只靠 Release 頁面的產物完成一次成功查詢；關閉程式後，本機服務會停止，Admin API Key 不會被寫入磁碟或瀏覽器儲存空間。

## 自動化驗證

在開發環境執行：

```powershell
python -m pip install -e .
python -m pip install -r requirements-dev.txt
python scripts\validate_models.py
python -m pytest -q
node --check web\js\app.js
```

Windows build 驗證：

```powershell
scripts\build_windows.bat
Get-FileHash dist\OpenAI-Free-Credit-Tracker.exe -Algorithm SHA256
```

預期結果：所有命令 exit code 為 0；`dist/` 中只有預期發行產物，且 EXE 可在沒有 Python 的 Windows VM 啟動。

## 驗收案例

### `AC-010-01` 乾淨 Windows 首次啟動（P0）

1. 建立未安裝 Python 的 Windows 10 或 11 VM。
2. 從草稿 Release 下載 EXE 與 checksum。
3. 驗證 SHA-256 後啟動 EXE。
4. 等待預設瀏覽器開啟。

預期：瀏覽器開啟 `127.0.0.1` 的隨機 port；頁面完整載入；未出現終端錯誤；工作目錄未產生設定或 Key 檔案。

### `AC-010-02` 有效 Admin Key 查詢（P0）

1. 輸入專用測試 Admin API Key。
2. 點擊更新。
3. 對照匿名化後的 OpenAI 後台數字。

預期：兩個群組只計入已確認的 incentivized tier；未知或非免費流量列在其他用量；Costs API 狀態清楚；畫面不顯示完整 Key。

### `AC-010-03` 無效 Key 與 API 錯誤（P0）

1. 依序測試空字串、錯誤 prefix、已撤銷 Key、無網路與模擬 429。
2. 每次查詢後檢查 UI、server log 與瀏覽器 Network response。

預期：錯誤訊息可行動、不含 Key；程式不崩潰；重試成功後可恢復正常。

### `AC-010-04` Key 不落地（P0）

1. 完成一次有效查詢後關閉程式。
2. 搜尋 application directory、使用者暫存目錄與瀏覽器 storage。
3. 搜尋 server log 與 Windows recent files。

預期：找不到完整 Admin API Key；重新啟動後輸入框為空。

### `AC-010-05` Loopback 與檔案邊界（P0）

1. 使用 `Get-NetTCPConnection` 檢查監聽介面。
2. 從同區網另一台機器嘗試連線。
3. 對 `/../`、URL encoded traversal 與不存在的資源發送請求。

預期：只監聽 loopback；其他主機無法連線；非法路徑回傳 403 或 404，且不洩漏本機路徑。

### `AC-010-06` 關閉與重啟（P1）

1. 關閉程式視窗。
2. 確認 port 已釋放。
3. 連續啟動與關閉三次。

預期：沒有殘留 process；每次都能正常啟動；不存在孤兒 server。
